import { Link } from '@nurvus/ui';

Opening another site: add `target` and `rel`, and say so in the text.
```jsx
import { Link } from '@nurvus/ui';

<Link href="https://github.com/kwehhh/nurvus-design-system" target="_blank" rel="noopener noreferrer">
  NURVUS UI on GitHub (opens in a new tab)
</Link>
```
